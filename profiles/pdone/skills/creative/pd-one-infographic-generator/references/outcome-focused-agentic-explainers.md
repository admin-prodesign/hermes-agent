# Outcome-focused bilingual agentic explainer infographics

Use this reference when creating employee-facing visuals that explain why PD One is different from a normal chatbot or ChatGPT.

## Positioning

Prefer explaining **what the agentic harness enables** over drawing too much internal architecture. Employees should understand the practical value first:

- Tools to do things / 工具能實際做事
- Memory of how work was done / 記得以前怎麼做
- More autonomy to finish tasks / 更自主地完成任務
- Company-safe boundaries / 公司規範內安全執行
- Proof, not just answers / 不只回答，還要有證據

A small architecture strip is useful, but keep it secondary:

`User request / 使用者需求 → Policy check / 權限確認 → Plan / 規劃 → Use tools / 使用工具 → Verify / 驗證 → Reply / 回覆`

## Recommended bilingual copy block

Headline:

- `Beyond Chat / 不只是聊天`

Subtitle:

- `PD One can help get work done / PD One 可以協助把事情完成`

Comparison strip:

- `Chatbot / 聊天機器人` — `Talks and suggests / 回答與建議`
- `PD One Agent / PD One 智慧助理` — `Acts within policy / 在授權範圍內執行`

Five main cards:

1. `Tools to do things / 工具能實際做事` — `Search, inspect, generate, browse, QA / 搜尋、檢查、產出、瀏覽、驗證`
2. `Memory of how work was done / 記得以前怎麼做` — `Skills and runbooks preserve proven workflows / 技能與流程手冊保存成功做法`
3. `More autonomy to finish tasks / 更自主地完成任務` — `Plans steps, calls tools, checks results / 規劃步驟、呼叫工具、檢查結果`
4. `Company-safe boundaries / 公司規範內安全執行` — `Identity, scope, approvals, data protection / 身分、權限、核准、資料保護`
5. `Proof, not just answers / 不只回答，還要有證據` — `Receipts, files, screenshots, status checks / 回執、檔案、截圖、狀態確認`

Bottom table rows:

- `Do work / 做事`: chatbot `Suggests / 建議`; PD One `Executes approved tools / 執行核准工具`
- `Repeat workflow / 重複流程`: chatbot `Forgets details / 容易忘細節`; PD One `Loads skills / 載入技能`
- `Complex task / 複雜任務`: chatbot `One reply / 單次回答`; PD One `Multi-step autonomy / 多步驟自主執行`
- `Safety / 安全`: chatbot `General filters / 一般限制`; PD One `Company policy gates / 公司政策把關`
- `Trust / 信任`: chatbot `Plausible text / 可能合理的文字`; PD One `Verified evidence / 經驗證的證據`

## Layout guidance

- Use a friendly outcome-first poster, not a dense engineering diagram.
- Keep English + Traditional Chinese short and paired on every major label.
- Put the PD One avatar near the header or right side as a guide holding a workflow tablet/checklist.
- Use one small architecture/process band only after the benefit cards.
- If exact bilingual wording must be preserved, switch to deterministic HTML/SVG/Pillow compositing rather than pure image generation.

## QA checklist

- Does the poster clearly answer: “What can PD One do that a chatbot cannot?”
- Are tools, memory, autonomy, safe boundaries, and proof all visible?
- Is every key label bilingual English + Traditional Chinese?
- Is the avatar visible, competent, and unclipped?
- Is small text non-critical or visually readable enough for a poster?
